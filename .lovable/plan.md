# خطة: مركز الإعلانات، إشعارات الحجز، ومسارات العملاء

## 1. صفحة «الإعلانات والفيديوهات» في لوحة التحكم
صفحة جديدة لمالك المنصة تجمع كل الوسائط الترويجية في مكان واحد:
- رفع فيديوهات إعلانية متعددة (أو لصق روابطها) مع اسم ووصف لكل إعلان.
- اختيار أي فيديو يظهر كخلفية للصفحة الرئيسية.
- تعديل شعار NOVAA الذي يظهر في نهاية الفيديو: رفع صورة الشعار، تشغيل/إيقاف بطاقة النهاية، تحديد حجمها، ودرجة شفافية الفيديو — بنفس لوحة الإعدادات الحالية.
- معاينة مباشرة لكل فيديو قبل نشره.

## 2. اختبار حجز حقيقي من الصفحة الرسمية
أنفّذ حجزًا فعليًا داخل المتصفح: اختيار الخدمة والوقت، إتمام الدفع، ثم متابعة ظهوره في وردية الحجز وتقريرها، وأصلح أي خلل يظهر أثناء المسار.

## 3. إشعار مباشر للعميل عند الحجز أو الدفع
- عند إنشاء حجز جديد أو تسجيل دفعة، يُسجَّل إشعار للعميل في قاعدة البيانات.
- يظهر الإشعار داخل تطبيق نوفنا (صفحة العميل) كجرس إشعارات مع عدد غير المقروء.
- يظهر أيضًا كتنبيه ترحيبي بعد تسجيل الدخول من صفحة دخول المتجر.

## 4. صفحة «مسار العميل»
صفحة تفصيلية لعميل واحد تعرض:
- كل حجوزاته (التاريخ، الخدمة، الأخصائي، الحالة).
- كل فواتيره ومدفوعاته وطريقة الدفع.
- الوردية المرتبطة بكل فاتورة وقيمة الكاش المتبقي فيها.
- ملخص أعلى الصفحة: إجمالي المشتريات، رصيد المحفظة، النقاط، عدد الزيارات.

## 5. صفحة «العملاء» الموسّعة
جدول لكل العملاء مع بحث وفلاتر، ولكل صف: عدد الحجوزات، إجمالي المدفوعات، آخر زيارة، والكاش المحصّل لكل وردية، مع زر يفتح صفحة مسار العميل.

## تفاصيل تقنية
- صفحات جديدة: `src/routes/_authenticated/platform-ads.tsx`، `customer-journey.$id.tsx`، وتوسيع `customers.tsx`؛ روابط في قائمة لوحة التحكم.
- الوسائط: إعادة استخدام `uploadPlatformVideo` / `VideoUploadField` وتخزين قائمة الإعلانات في `platform_settings.home.ads` (JSON) مع `heroVideoUrl` المختار.
- الإشعارات: كتابة صفوف في `notification_events` (kind: `booking_created` / `payment_received`, channel `inapp`) عبر مُشغِّلات قاعدة بيانات على `bookings` و`invoice_payments`، مع سياسة قراءة للعميل المالك فقط + عمود `read_at`.
- بيانات المسار: دالة قراءة واحدة تجمع `bookings` + `invoices` + `invoice_payments` + `cash_shifts` لكل عميل، مع فلترة الفرع الحالي.
- الاختبار: Playwright على المعاينة المحلية لمسار الحجز والدفع، ثم التحقق من تقرير الوردية.
